# 3D Wireframe Canvas

A lightweight **3D wireframe engine** built with **JavaScript and HTML5 Canvas**. Render cubes, pyramids, walls, and spheres using a simple pseudo-3D perspective projection. Move and rotate a camera in 3D space for an interactive experience.

---

## Purpose

Trying to understand 3D graphics concepts by applying what I study. This project helped me gain a more intuitive understanding of some linear algebra fundamentals.

---

## Features

- **Build your own map with 3D Shapes:** Cubes, pyramids, walls, and recursive spheres (not really spheres)
- **Camera Movement:** Navigate freely in X, Y, Z axes
- **Rotation Controls:** Rotate camera with arrow keys
- **Perspective Projection:** Simulates depth on a 2D canvas
- **Vanilla JS:** No external libraries required
- **Save and load your creations:** Save as json files 

---

## Controls

| Key                | Action                                |
|--------------------|---------------------------------------|
| Arrow Up / Down    | Rotate camera X-axis (pitch)          |
| Arrow Left / Right | Rotate camera Y-axis (yaw)            |
| W / S              | Move camera forward/backward (Z-axis) |
| A / D              | Move camera left/right (X-axis)       |
| Q / E              | Move camera up/down (Y-axis)          |
| Spacebar           | Place block                           |
